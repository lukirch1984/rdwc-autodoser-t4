# Contributing Guidelines

We welcome contributions to the RDWC Auto-Doser T4 project!

## How to Contribute
1.  **Fork** the repository.
2.  Create a **Feature Branch** (`git checkout -b feature/AmazingFeature`).
3.  **Commit** your changes.
4.  **Push** to the branch.
5.  Open a **Pull Request**.

## Coding Standards
*   Use **C++11** standards.
*   Keep `drivers/`, `ui/`, and logic separate.
*   Document complex logic.
*   Run `pio run` to ensure compilation before pushing.

## Reporting Bugs
Please use the GitHub Issues tab to report bugs. Include:
*   Hardware revision
*   Logs (Serial Monitor)
*   Steps to reproduce
