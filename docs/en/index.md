# Welcome to RDWC Auto-Doser T4

This is the official documentation for the **RDWC Auto-Doser T4**, an open-source hydroponic controller based on the LILYGO T4 ESP32 display.

## Features
- **Automated Dosing:** pH Up/Down & Nutrients A/B
- **Monitoring:** pH, EC, Water Temp, Water Level
- **Interface:** Touch display & Web Dashboard
- **Open Source:** MIT Licensed
