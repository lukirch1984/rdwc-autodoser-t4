# Bill of Materials (BOM)

## 1. Core Electronics
*   **Controller:** LILYGO T4 V1.3 (ESP32)
*   **ADC Module:** ADS1115 (16-bit, I2C) - *Essential for accurate pH/EC*
*   **I/O Expander:** PCF8574 (I2C) - *Essential for Relays*
*   **Power Supply:** 12V DC (5A)
*   **Buck Converter:** LM2596 (12V -> 5V)

## 2. Sensors
*   **pH Sensor:** Analog BNC Probe + Interface Board (3.3V/5V compatible)
*   **EC Sensor:** Analog Conductivity Probe (K=1.0)
*   **Temperature:** DS18B20 (Waterproof)
*   **Level:** HC-SR04 (Ultrasonic)

## 3. Actuators
*   **Relay Module:** 4-Channel 5V Relay (Active Low preferred)
*   **Pumps:** 4x 12V Peristaltic Dosing Pumps

## 4. Misc
*   Jumper Wires (Female-Female, Male-Female)
*   Silicon Tubing (Food grade)
*   Calibration Buffers (pH 4/7, EC 1413µS)
*   Enclosure (IP65 recommended)
