# Richtlinien für Beiträge

Wir freuen uns über Beiträge zum RDWC Auto-Doser T4 Projekt!

## Wie man beiträgt
1.  **Forke** das Repository.
2.  Erstelle einen **Feature Branch** (`git checkout -b feature/TollesFeature`).
3.  **Committe** deine Änderungen.
4.  **Pushe** auf den Branch.
5.  Öffne einen **Pull Request**.

## Coding Standards
*   Nutze **C++11** Standards.
*   Halte `drivers/`, `ui/`, und Logik getrennt.
*   Dokumentiere komplexe Logik.
*   Führe `pio run` aus, bevor du pushst.

## Fehler melden
Bitte nutze die GitHub Issues, um Bugs zu melden. Enthalte:
*   Hardware-Revision
*   Logs (Serieller Monitor)
*   Schritte zum Reproduzieren
