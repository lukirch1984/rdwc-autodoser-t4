# Willkommen beim RDWC Auto-Doser T4

Dies ist die offizielle Dokumentation für den **RDWC Auto-Doser T4**, einen Open-Source Hydroponik-Controller auf Basis des LILYGO T4 ESP32 Displays.

## Funktionen
- **Automatische Dosierung:** pH Up/Down & Dünger A/B
- **Überwachung:** pH-Wert, EC-Wert, Wassertemperatur, Füllstand
- **Interface:** Touch-Display & Web-Dashboard
- **Open Source:** MIT Lizenz
