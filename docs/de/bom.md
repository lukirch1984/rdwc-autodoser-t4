# Einkaufsliste (BOM)

## 1. Elektronik-Kern
*   **Controller:** LILYGO T4 V1.3 (ESP32)
*   **ADC Modul:** ADS1115 (16-bit, I2C) - *Zwingend für pH/EC*
*   **I/O Expander:** PCF8574 (I2C) - *Zwingend für Relais*
*   **Netzteil:** 12V DC (5A)
*   **Buck Converter:** LM2596 (12V -> 5V)

## 2. Sensoren
*   **pH Sensor:** Analoge BNC Sonde + Interface Board
*   **EC Sensor:** Analoge Leitfähigkeits-Sonde (K=1.0)
*   **Temperatur:** DS18B20 (Wasserdicht)
*   **Level:** HC-SR04 (Ultraschall)

## 3. Aktoren
*   **Relais Modul:** 4-Kanal 5V Relais (Active Low bevorzugt)
*   **Pumpen:** 4x 12V Peristaltik-Dosierpumpen

## 4. Sonstiges
*   Jumper Kabel
*   Silikonschlauch (Lebensmittelecht)
*   Kalibrierlösungen (pH 4/7, EC 1413µS)
*   Gehäuse (IP65 empfohlen)
